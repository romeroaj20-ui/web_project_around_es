# Tripleten web_project_around_es

Nombre del proyecto: Around the US

Descripción del proyecto: pagina web realizada a traves de VS Code como herramienta para elaborar la progamcación del apartado de HTML, CSS y JavaScript que se uso en la refinacion de la página web y para funcionamiento al momento de que la pagina cobre vida con todas las funcionalidades que la misma presenta.

Tecnologías y técnicas usadas: Se utilizo tanto HTML, CSS, JavaScript y TypeScript asi como el uso de un Api para la elaboracion de esta página web.

Lista de funcionalidades: creación y actualización de tarjetas, se le puede dar likes a las cartas y tambien quitarselo, se puede editar el perfil como quieras,se realiza una validación de formularios para que sean completados de forma correcta, se programaron diferentes maneras de cerrar las ventanas emergentes que posee. Tambien se ha realizado el tipado de las clases para generar mayor seguridad y cohecion del codigo. Y por ultimo se ha configurado para acceder y obtener datos desde una Api.

Link para visualizar el proyecto: https://romeroaj20-ui.github.io/web_project_around_es/
